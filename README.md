# 가상 영어 교실

영어 뉴스 기사(PDF)를 올리고 AI 선생님·반 친구들과 토론하는 연습용 웹앱 데모 (아이폰 홈 화면 앱 지원)

| 단계 | 기능 |
|---|---|
| 자료 넣기 | PDF 업로드 또는 링크로 기사 불러오기, 요약·단어 카드, 원문 보기 |
| 교실 입장 | 원탁 좌석, 선생님·친구 소개, 목소리 켜기 |
| 토론 | 찬반 토론, 손들기, 영어로 답변 작성 |
| 내 생각 노트 | 단어장, 생각 정리, 문장 교정 카드 |

- PDF는 기기 안에서만 읽어요 (pdf.js). 서버로 보내지 않아요.
- 단어 카드·내 생각 노트는 이 기기 브라우저에만 저장됩니다.
- 현재 토론 대사는 예시 대본이며, 진짜 AI 연동은 예정되어 있어요.
- 회원가입·광고·분석 도구 없음
